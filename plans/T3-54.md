## 공통 설계
- **돌아올 주소**: 프론트 주소의 `/auth/kakao/callback`. 배포 입구가 프론트로만 보내므로 프론트가 `/auth/*`를 백엔드로 넘긴다.
  값은 `KAKAO_REDIRECT_URI`로 고정하고 요청 헤더에서 만들지 않는다.
- **로그인 요청 위조 방지**: 로그인 시작 때 임의 `state`를 짧은 수명의 httpOnly 쿠키에 두고 callback에서 대조한다. 로그인 뒤 돌아갈 화면은
  우리 서비스 안의 경로(`/`로 시작, `//`·`\` 거부)만 허용한다.
- **쿠키**: httpOnly, SameSite=Lax, HTTPS에서는 Secure. 쿠키로 인증하는 쓰기 요청(로그아웃·삭제)은 Origin도 확인한다.
- **카카오 토큰은 저장하지 않는다.** 회원번호·닉네임을 읽고 버린다. 키·토큰·code는 로그와 trace에 남기지 않는다.
- **테이블**: `users`(id, kakao_id 유일, nickname, created_at, last_login_at), `conversations`에 `user_id`·`title`·`updated_at`,
  `messages`는 그대로(질문 = user, 답 = assistant + `result`).
- **회원 대화의 주인**: `chat_sessions.user_id` 추가. 회원 대화도 이 표에 두되 만료 조건은 `user_id IS NULL`만. 소유 검사는 user_id가 먼저라
  비회원이 회원 대화 ID를 알아도 이어받지 못한다. 저장소가 실패하면 보낸 ID를 쓰지 않고 새 ID로 답한다(지금 `_open`은 보낸 ID를 그대로 씀).
- **대화 ID**: 회원은 UUID로 읽어 한 표기로 통일. 형식이 아니면 새 대화(상세·삭제는 404).
- **턴 저장**: 대화 행을 잠그고 `MAX(turn)+1`, 질문과 답을 한 트랜잭션으로 저장. 체크포인트 개수로 번호를 정하지 않는다. 중단·오류 턴은
  저장하지 않고, 저장이 실패해도 답은 보낸다. 같은 대화의 동시 질문은 409(제안).
- **삭제**: 체크포인트를 먼저 지우고 행을 지운다(지금 API는 반대라 실패하면 체크포인트가 남고 배치도 못 찾음). 스트리밍 중 삭제되면
  턴을 저장하지 않고 체크포인트를 다시 지운다.
- **피드백**: `chat_requests.user_id`로 주인 확인. 로그에 계정 ID는 남기지 않고 `is_member`만 넘긴다.
- **장애 분리**: 세션 조회 실패를 비회원으로 처리하는 것은 `/chat/stream`만. 목록·상세·삭제·`/auth/me`는 503. 카카오 호출은 시간 제한.
- **정리 배치**: `conversations.updated_at` 기준 90일 지난 대화·턴·체크포인트와 만료된 로그인 세션을 지운다.
- **프론트 전달**: next.config rewrite는 쓰지 않는다(목적지가 빌드 때 고정, `/chat`은 화면 주소와 겹침). `app/auth/[...path]/route.ts`가
  302와 여러 `Set-Cookie`를 그대로 넘기고 `no-store`. 목록·상세·삭제는 `/api/*` 프록시. 채팅 프록시는 쿠키와 `X-Session-Id`를 넘긴다
  (지금은 안 넘겨 모든 비회원이 세션 없음으로 묶임). 로그인은 `<Link>`가 아니라 `<a>`(미리 불러오기 방지).
- **로그**: 접근 로그에서 `/auth/kakao/callback`의 쿼리(`code`·`state`)를 지운다. 카카오 오류 본문은 기록하지 않는다.
- **세션 수명**: 로그인 시점부터 14일, 연장 없음. 로그인마다 새 토큰. 카카오에서 연결을 끊어도 최대 14일은 유효.
- **보안 세부**: state는 1회용이고 돌아갈 화면과 묶는다. Origin 허용값은 설정으로 고정하고 `/chat/stream`도 확인. Secure는 설정값(로컬 http만 끔).
- **DB**: 정렬용 인덱스 `(user_id, updated_at, id)`, 기존 `conversations` 행은 `user_id` NULL 허용. 메모리 SQLite에도 새 표와 외래 키 켜기.
- **문서**: api.md 6장·9장(쿠키 서명 키 삭제), `models.py`·`store.md`의 "식별자 없음" 설명 수정.
